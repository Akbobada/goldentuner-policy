GoldenTuner 계정 및 데이터 삭제 안내

GoldenTuner는 현재 회원가입 및 로그인 기능을 제공하지 않으며, 회사 서버에 이용자 계정이나 개인정보를 저장하지 않습니다.

기기 내부 데이터 삭제 방법

  • Android: 설정 → 애플리케이션 → GoldenTuner → 저장공간 → 데이터 삭제
  • iOS·iPadOS: GoldenTuner 앱을 삭제하면 앱 내부에 저장된 데이터가 함께 삭제됩니다.

삭제되는 정보

  • 기기 내부에 저장된 튜너 PCM 기록 및 분석 로그
  • 메트로놈 동작 로그
  • 앱 내부 설정 및 임시 데이터

문의

데이터 삭제와 관련한 문의는 goldenear.support@gmail.com으로 연락해 주세요.

GoldenTuner Account and Data Deletion

GoldenTuner currently does not provide account registration or login and does not store user accounts or personal information on Company servers.

How to Delete Local App Data

  • Android: Settings → Apps → GoldenTuner → Storage → Clear data
  • iOS and iPadOS: Uninstalling GoldenTuner deletes data stored within the app.

Information Deleted

  • Locally stored tuner PCM recordings and analysis logs
  • Metronome operation logs
  • App settings and temporary data

Contact

For questions regarding data deletion, contact goldenear.support@gmail.com.
